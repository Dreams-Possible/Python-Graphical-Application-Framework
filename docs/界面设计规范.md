# 界面设计规范

## 定调

应用是“日常信息仪表台”：时钟提供稳定节奏，天气提供时间维度的数据，日志与设置负责可解释和可维护。使用浅色面板、深色文字与蓝色状态强调，避免依赖平台默认主题。全部页面共用左侧导航和右侧内容区。

## 视觉令牌

设置 → 外观提供“跟随系统”“Daylight · 浅色”“Nightfall · 深色”，默认跟随系统，独立保存为 `appearance.json`。保存后立即生效，不重建窗口、不重置页面或任务。系统未提供偏好时回退浅色；显式选择浅色/深色不受系统变化影响。

主题统一维护语义颜色、Qt 调色板和控件样式；深色不是简单反色。已有日志富文本随主题重新着色，隐藏页面在下次显示时使用新主题。保留大字号等宽时钟作为视觉重点，其余控件克制、统一。

| 深色语义 | 值 |
| --- | --- |
| 页面 / 面板 | `#151C28` / `#1E2939` |
| 主文字 / 辅助文字 | `#E7EDF6` / `#A6B6CA` |
| 强调 / 选中背景 | `#8BB0FF` / `#30466C` |
| 边框 | `#35475F` |
| 成功 / 警告 / 错误 | `#6BD4B3` / `#E9BD70` / `#FF98A7` |

设置类别采用整行圆角选中态，禁止文本编辑，不画文字周围的原生细框；键盘焦点以整行边框表达。下拉框统一使用列表弹层、行高、留白和箭头。不能为去掉细框而禁用键盘焦点。

系统偏好接口：[Qt QStyleHints](https://doc.qt.io/qtforpython-6/PySide6/QtGui/QStyleHints.html)。跟随系统取决于桌面平台是否向 Qt 提供通知，窗口标题栏仍由操作系统管理。

浅色令牌：

数值输入框统一定义上下按钮的尺寸、分隔线、圆角、悬停和按压态，箭头使用随主题切换的资源，不能混用原生按钮边框。输入区预留右侧操作空间，保留直接输入和键盘上下键操作。

正文采用系统可用的中文无衬线字体；日期、时间和日志使用等宽字体族回退。页面标题 26 px，模块标题 17 px，正文 14 px，注释 12 px，主时钟 64 px。留白以 8 px 为基本单位，页面内边距 28 px，卡片内边距 20 px，卡片圆角 14 px。

## 页面组织

- 固定导航宽度约 180 px，显示应用标识、四个入口和底部运行状态。选中项有背景及文字变化，不只依赖颜色。
- 时钟：日期、超大等宽时间、时区、同步状态、偏差、最近同步时间；手动同步与取消位于同一操作区。
- 天气：保留当前天气与搜索地点入口，底部胶囊悬浮在内容上方，详情留出底部滚动余量。详情按当前条件摘要、未来 24 小时、每日预报、历史归档纵向平铺，外层支持鼠标按住纵向拖动和惯性滚动，仍保留滚动条及滚轮。小时列标题只显示数字时间，当前小时保留高亮；每日与历史列保留日期和星期。三个趋势区域统一横向排列，使用天气线条图标、温度曲线与降水摘要，每日和历史展示最高/最低温双曲线。仅当前小时和今天使用主题高亮背景及强调文字。鼠标左键按住横向拖动时滚动内容，松手后支持惯性滚动；移动超过系统拖动阈值后不得展开详情，拖回原点也不算点击。仅在同一列原地松开时原地加宽，以强调色边框表示选择，不改变该列背景，右侧在列内展示详细数据；再次点击同列收起，点击其他列时原列恢复宽度、新列展开，Esc 也可收起。普通列宽 104，展开列宽 280；没有悬停计时或详情弹窗，数据更新时清除展开状态。图形随深浅主题变化，缺失温度不连线；空数据明确提示。历史保持“归档”标记，不添加无数据来源的指标。
- 日志：首行选择实时/历史会话、刷新列表、打开日志位置、清除全部日志；次行等级筛选、跟随最新、清空视图。历史模式禁用跟随最新，不混入实时事件；文件操作期间禁用重复操作。清除全部须确认，提示不可撤销及当前会话仍会继续记录；清空视图不删除文件。正文按等级着色，保留时间和模块来源，历史截断必须提示。
- 设置：左侧注册类别，右侧滚动表单；“保存设置”保存编辑，“恢复当前分类默认配置”须确认，随后立即覆盖该分类配置并更新表单，不需要再次保存。提示明确范围及无自动撤销；默认选中取消。未保存编辑不会被自动刷新覆盖。另有本地文件管理类别。

## 行为一致性

按钮命名表达动作。请求执行中显示状态并提供取消；重复请求不可叠加。同一页面的手动与周期刷新共用入口。网络失败显示简短原因并保留有效旧数据；恢复成功后清除旧错误。

工作线程不得直接改控件；高频事件合并后再发布，列表使用追加或模型更新。多个异常使用同一个非模态通知窗口；关闭通知不影响任务状态。隐藏页面停用昂贵渲染。

所有输入框、选择框、复选框、表头、滚动条和禁用态都由统一主题覆盖。正文和提示可选择复制；焦点边框清晰，按钮可键盘操作。小窗口优先滚动和伸缩布局，不缩小文字。这里不使用持续动画或半透明背景，保证各桌面平台表现一致。

## 文案与语言切换

遵循[应用架构设计规范](应用架构设计规范.md)中的展示资源边界。页面标题、菜单、按钮、字段、提示、表头和无障碍说明使用资源键；代码不以翻译后的文字判断状态。日期与星期按软件语言格式化，位置与时区仍独立决定所显示的日期和节假日地区。

中英文使用同一套控件与交互。切换语言保留焦点相关的输入、选择、展开状态和后台任务；长文本优先换行或伸缩布局，图表窄列允许省略并提供完整悬停内容。默认语言资源缺失时必须显式提示，不以空白代替。用户输入、外部名称和历史日志正文不自动翻译。

## 公共拖动与切页

`shared/gestures.py` 提供 `DragClickWidget`（原地释放才点击）、`KineticScrollArea`（定向拖动和惯性滚动）、`SwipePages`（跟手切页及回弹）三个公共基类。`IslandPages` 继承 `SwipePages`，仅负责浮岛外观及选中按钮同步；时钟和天气共用切页行为，天气详情和设置表单使用公共滚动区域。阈值、切页动画时间与边界阻尼集中在 `ui_metrics.py`。

一次按下只确定一个手势归属：横向滚动区域优先处理横向拖动，纵向拖动交给外层纵向区域；普通内容区的横向拖动交给浮岛页面容器。确定方向后到释放前不换目标，图表到边界也不继续切页。输入框、按钮、选择框、滑块、表格和列表保留自身操作；自定义交互控件可通过 `excludeSwipe` 明确排除。

页面在拖动时跟手移动；短距离慢拖回到原页，超过距离阈值或快速甩动时切换相邻一页。首尾页只回弹，不循环。点击浮岛与拖动共用同一选中状态；窗口缩放、隐藏或失去激活时结束当前手势。滚轮、滚动条和键盘操作保持可用。

日历年／月视图支持按住左右拖动切换相邻周期，左拖进入下一年／月、右拖进入上一年／月；拖动期间跟手显示相邻周期，结束后复用中间槽。原地释放才确认日期，双击月或日保留下钻，普通表格和列表仍保留原生拖选。日视图历史区使用少量编辑精选周年，按年份倒序排列，最近年份在上；说明与来源合并为底部状态行，完整信息在悬停提示显示。更新节假日与回到今天相邻排列，工具栏在窄宽度下按组换行。

日视图也复用周期滑动容器：横向拖动预览前后一天，纵向拖动浏览当前日内容，链接按钮保留点击行为。仅松手确认新日期后加载该日精选周年；相邻日期只展示日期、节假日和预览说明，不预取历史数据。切换到新日期从内容顶部显示。

年、月、日周期切换期间，公共容器给相邻面板绘制强调色圆角边框和边缘留白，形成明确分界；停稳后保留统一边框，保留原有日期选择边框。过渡框不接收鼠标事件，颜色读取应用调色板，边框宽度、圆角及留白由 `ui_metrics.py` 管理。

日历年、月、日均常驻统一的圆角强调边框与留白，内容位于框内，避免边框遮挡滚动条。历史正文优先使用软件当前语言，缺失或失败统一回退英文。原文就绪先显示英文和翻译状态；对应译文完成后逐条替换，并允许悬停核对原文。英文不发起翻译，后续新增语言使用对应目标，不以“非中文”一概归为英文。日历不再提供单独的中英文选项。
